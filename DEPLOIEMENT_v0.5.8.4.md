# Déploiement LTS v0.5.8.4

Cette mise à jour est uniquement front-end. Ne redéploie pas Apps Script.

1. Garde `write_enabled = FALSE`.
2. Dans le dépôt GitHub relié à Cloudflare Pages, remplace `index.html` et `api-client.js`.
3. Commit conseillé : `LTS v0.5.8.4 - fix imported stimulus counters`.
4. Attends le déploiement Cloudflare.
5. Ouvre `https://lts-beta.pages.dev/?v=0584`.
6. Dans Coach → Réglages, lance `Tester la connexion`.
7. Ouvre la semaine 5 et contrôle notamment Gainage, Prévention, Mobilité, Running, Escalade, Doigts, Tirage et Poussée.
8. Laisse les écritures désactivées jusqu’à validation visuelle.
